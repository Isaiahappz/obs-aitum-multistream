Aitum Multistream is installed

  1. Open OBS Studio.
  2. In the menu bar choose Docks, then tick Aitum Multistream.

Your scenes, profiles and stream keys were not changed. Any outputs you had already set up in Aitum Multistream are still there.

To remove the plugin later, use Uninstall Aitum Multistream, which came alongside this installer. It removes only the plugin; your outputs and stream keys are kept unless you say otherwise.

Installed to: ~/Library/Application Support/obs-studio/plugins/aitum-multistream.plugin

Install log: ~/Library/Logs/Aitum Multistream Installer.log
