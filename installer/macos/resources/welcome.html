Aitum Multistream for OBS Studio

This adds the Aitum Multistream panel to OBS Studio, so you can send one programme out to several places at once.

What this installer does

  • Puts one plugin file in your own OBS plugins folder. No administrator password is needed.
  • Removes any older copy of Aitum Multistream, so OBS never loads two.

What it does not touch

  • Your scenes, sources and profiles.
  • Your stream keys and the outputs you have already set up in Aitum Multistream. They stay exactly as they are.
  • Any other OBS plugin.

OBS Studio 33.0 or newer is required. If this Mac has an older OBS, the installer will stop and offer to open the OBS download page. If OBS is open right now, the installer will ask you to quit it first.
